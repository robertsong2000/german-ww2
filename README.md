# 二战德国史调研

面向历史学习者的 **1933–1945 德国史** 系列报告：学术、批判、以档案与严肃史学为据。不美化该政权，不把战争写成武器图鉴或领袖传记。暴行按已确立的史实书写。

本仓库目前收有第 **1–29 期**。第 30 期起按第二轮主题池循环：政治、战争、民生社会三条线补缺。每篇是一份可单独打开的 HTML（内联 CSS，无需构建）。

## 怎么读（避免显得零散）

按三条线读，不必按期号顺序：

- **政治**：第 1、12、13、14、21、29 期；第二轮 30–36。
- **战争**：第 4–6、8、15–17、23、24、26 期；第二轮 37–43。
- **民生与社会**：第 3、7、9、10、11、19、20、28 期；第二轮 44–52。

第二轮未做条目见 [`调研报告/调研记录.md`](调研报告/调研记录.md)。

## 体例

每篇报告至少包含：本期主题、核心发现、可核对的来源链接、给历史学习者的启示。正文为中文。每期使用互不重复的视觉风格。

优先引用档案馆、同行评议著作、纪念馆与高质量新闻；新近节点（约 2025–2026）用来把旧问题接回当前公共讨论，而不是把历史缩成“今年热点”。
